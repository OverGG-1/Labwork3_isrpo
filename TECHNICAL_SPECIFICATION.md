# Техническое задание на разработку TaskTracker
## 1. Общие сведения
**Наименование:** TaskTracker.  
**Тип продукта:** плагин для VSCode.  
**Язык реализации:** TypeScript.  
**Среда выполнения:** Node.js / Extension Host VS Code.

## 2. Назначение и цель
Расширение предназначено для обнаружения специальных маркеров задач в комментариях исходного кода и текстовых файлах проекта. Цель — предоставить разработчику единый интерфейс для просмотра, поиска, фильтрации и навигации по таким задачам.

## 3. Функциональные требования
Система должна:
1. Получать файлы текущего рабочего пространства.
2. Исключать каталоги и файлы, заданные настройками.
3. Пропускать бинарные файлы и файлы, превышающие установленный лимит размера.
4. Распознавать маркеры `TODO`, `FIXME`, `BUG`, `HACK`.
5. Сохранять для каждой задачи тип, текст, URI, относительный путь и номер строки.
6. Отображать задачи в отдельном представлении VS Code.
7. Предоставлять фильтрацию по типу задачи.
8. Предоставлять поиск по тексту задачи и пути файла.
9. Поддерживать сортировку по имени файла, типу и номеру строки.
10. Открывать исходный файл и переводить курсор к выбранной задаче.
11. Обновлять сведения после создания, изменения и удаления файлов, а также после редактирования открытого документа.
12. Отображать декорации файлов и подсветку строк, если соответствующие настройки включены.
13. Предоставлять команду полного обновления и команду сброса фильтров.

## 4. Нефункциональные требования
- Расширение должно работать внутри Visual Studio Code и использовать VS Code Extension API.
- Основной язык реализации — TypeScript.
- Работа должна выполняться локально, без обязательного подключения к внешнему серверу.
- Ошибка чтения одного файла не должна прерывать анализ остальных файлов.
- Должны быть предусмотрены настройки исключений и максимального размера файла.
- Код должен быть разделён на логические модули и снабжён комментариями.
